# PayControl · atrpay Payment Hub

**A modern, secure, and scalable dashboard for managing crypto wallets, bank accounts, and payment gateways.**

![PayControl Dashboard](https://via.placeholder.com/1200x630/07090F/3D8EF0?text=PayControl+Dashboard)

---

## ✨ Features

- **💰 Crypto Wallets**: Track balances, send/receive, and swap assets across Bitcoin, Ethereum, Solana, and more.
- **🏦 Bank Accounts**: Connect via Plaid to view balances and transaction history.
- **⚡ Payment Gateways**: Manage Stripe, PayPal, Wise, and other payment processors.
- **📊 Profit Allocation**: Define rules for automated profit distribution.
- **📈 Transactions**: View and filter all transactions across all sources.
- **🔒 Secure**: JWT authentication, HTTPS, rate limiting, and input validation.
- **📱 Responsive**: Works on desktop, tablet, and mobile.
